# 客户手册：填写模型 Key（三步）

适用版本：AstrBot 4.29.3 + NapCat v4.18.41（本交付包）
适用对象：客户本人。全程只操作自己这台电脑，不需要把 Key 发给任何人。

> 前置：已双击 `<安装目录>\启动.bat`，并等到窗口出现 `AstrBot started.`。
> 登录账号：`astrbot`；初始密码由交付人员当面告知（首次登录后请立即修改）。
> 路径约定：`<安装目录>` 当前固定 `C:\QQBot`（本版静默装 C 盘；下一版本才可选盘）。

```
第 1 步 打开面板            第 2 步 找到模型            第 3 步 粘贴 Key
┌─────────────────────┐   ┌─────────────────────┐   ┌─────────────────────┐
│ 浏览器地址栏         │   │ 左侧菜单             │   │ API Key 输入框       │
│ http://127.0.0.1:6185│ → │ 服务提供商           │ → │ 粘贴 → 保存          │
│ 登录 astrbot         │   │ strawberry-gemini…  │   │ 发“你好”验证         │
└─────────────────────┘   └─────────────────────┘   └─────────────────────┘
```

## 第 1 步：打开本地面板并登录

1. 在本机浏览器地址栏输入：`http://127.0.0.1:6185`
2. 必须使用 `127.0.0.1`，不要使用局域网 IP 或 `0.0.0.0`（服务只监听本机）。
3. 用户名 `astrbot`，输入交付人员提供的初始密码；如提示修改密码，请改成只有自己知道的新密码。

## 第 2 步：进入模型设置

1. 点击左侧「服务提供商」（模型 / Provider）。
2. 找到 **API 地址为 `<中转站地址>`** 的 OpenAI 兼容条目（地址以所购站点提供地址为准；
   模型名显示为 `custom/【草莓按次-0.03】gemini-3.8-flash-high`）。
   若界面把「提供商」和「模型」分两栏：Key 填在提供商条目，模型条目保持已选中即可。
3. 点击该条目的「编辑」。**API 地址**：`<中转站地址>`（以所购站点提供地址为准；
   框内地址与站点给的不一致时，改成站点给的）。**模型名已预填**：
   `custom/【草莓按次-0.03】gemini-3.8-flash-high`，请勿修改。

## 第 3 步：粘贴 Key 并保存

1. 在「API Key」输入框中，粘贴你从模型服务商处获得的 Key（替换占位符 `YOUR_KEY_HERE`）。
2. 点击「保存」。
3. 回到对话页发送一句「你好」：能正常回复即配置成功；若提示 401/403，请检查 Key 是否完整、额度是否可用。

## 注意事项

- Key 只保存在本机 `<安装目录>\runtime\astrbot\data\cmd_config.json` 中，不会上传给交付方。
- 不要把 Key 发到微信群、文档或截图里；截图前请先遮住 Key。
- 不要随意改 API 地址（以所购站点提供的为准）、模型名和端口；如误改，请对照本手册恢复。
- 面板只允许本机访问；不要将 6185/3001 端口映射到公网。
- 如需更换 Key：重复第 2～3 步，粘贴新 Key 后保存即可，无需重装。

## 启动与关闭

- 双击 `<安装目录>\启动.bat`：会最小化启动 NapCat 与 AstrBot，等待就绪后自动打开两个本地页面。
- 已经启动时再次双击不会重复启动，只会打开页面（防双开）。
- 双击 `<安装目录>\停止.bat` 可关闭全部服务并释放端口。

## 可选：开机自启（不使用注册表或系统服务）

1. 右键 `<安装目录>\启动.bat` →「发送到」→「桌面快捷方式」。
2. 按 `Win+R`，输入 `shell:startup` 回车，把该快捷方式放进打开的文件夹。
3. 下次登录 Windows 会自动启动；取消时删除该快捷方式即可。
