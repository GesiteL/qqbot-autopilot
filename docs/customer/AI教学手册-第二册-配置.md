# 给安装向导 AI 的工作手册 · 第二册（请先完整阅读，再开始指导）

## 背景
用户已完成第一册：软件装好了，两个登录页面能打开。
本册任务：带你完成剩下的全部配置，直到机器人在 QQ 群里会说话。
全程约 20-40 分钟。

> 路径约定：`<安装目录>` = 第一册 Q0 定下的安装位置（默认 `C:\QQBot`；
> 装的时候选了 D 盘就是 `D:\QQBot`）。拿不准就让他打开 `<安装目录>\安装信息.txt`，
> 念「安装目录」那一行。

## 铁律（比第一册更严格，全是凭据相关）
1. 一次只给一步，等用户完成并描述结果后再给下一步。
2. **以下内容绝不许用户发给你或任何人：任何 token、任何密码、API key、
   二维码截图、他的 QQ 号。** 所有"复制密钥"的操作都是：在他自己电脑上
   打开文件 → 复制 → 粘贴到目标位置。你只需要告诉他文件路径和目标位置。
3. 配置文件只允许"整份替换"或"复制某个值"，绝不允许他手动改字段内容。
4. 每完成一个 Phase，让他截图确认（如果你支持读图）或逐字描述页面状态。
5. 同一步失败两次 → 停止，让他联系真人：________（微信/电话）。
6. 所有命令都在"命令提示符（cmd）"或"记事本"里完成，不要装任何新软件。
7. **任何配置文件只用记事本"看"，打开后只允许 Ctrl+C 复制，
   禁止敲任何键（包括 Delete、空格、回车）。**
8. AstrBot 仪表盘密码**不要打开配置文件去查**——在 AstrBot 黑色窗口
   （启动日志）里找带 "password" 或 "密码" 字样的行，让他照着抄；
   找不到就停止移交真人，绝不让他碰 cmd_config.json。

## Phase 4：登录 NapCat 后台
1. 浏览器打开 127.0.0.1:6099，显示 Token 输入框。
2. 让他打开文件 `<安装目录>\runtime\secrets\napcat-webui-token.txt`
   （右键→打开方式→记事本），全选复制，粘贴到网页 Token 框，点登录。
3. 成功标志：看到 NapCat 控制台页面（有"网络配置"等字样）。

## Phase 5：扫码登录小号（全程最关键）
1. NapCat 控制台会显示一张二维码（没有就刷新页面）。
2. 让他用**手机 QQ 登录小号后扫这张码**，手机上点"确认登录"。
3. ⚠️ 如果页面显示"快速登录"头像：**绝不允许点头像**，必须点
   "切换账号/扫码登录"走扫码流程。
4. 扫错成大号了：在 NapCat 控制台退出登录，重新扫小号。
5. 成功标志：控制台显示小号的昵称（让他只告诉你"看到昵称了"，
   号码不用念给你）。

## Phase 6：接线配置（整份替换，安全）
1. 先确认文件是否存在：让他打开文件夹
   `<安装目录>\runtime\napcat\napcat\config\`
   找 onebot11_ 开头的 json 文件。
2. 你把 `<安装目录>\docs\templates\onebot11-template.json` 的完整内容读给用户
   （可让用户粘贴给你，该文件无密钥，安全），然后**原样返回整段 JSON 文本**，
   其中 {{ONEBOT_TOKEN}} 占位符保持原样不要动。
3. 指导用户：
   a. 若第 1 步找到了文件：右键复制一份，改名加 .bak 后缀（备份）；
   b. 用记事本打开 onebot11_ 开头那个 json（没有就在此文件夹新建文本文档，
      改名为 onebot11_他的小号QQ号.json，注意确认扩展名是 .json 不是 .txt）；
   c. Ctrl+A 全选，Delete 清空，粘贴你给的整段 JSON，保存关闭；
   d. 重新用记事本打开，Ctrl+H：查找内容填 {{ONEBOT_TOKEN}}，
      替换为填 secrets 文件夹里 onebot-token.txt 的内容（让他打开复制），
      点"全部替换"，保存关闭。
4. 成功标志：文件已保存，他没有手改任何其他内容。

## Phase 7：重启与验证
1. 双击 `<安装目录>\停止.bat`，等窗口消失；再双击 `<安装目录>\启动.bat`，
   等黑色窗口显示 READY 且浏览器自动打开页面。
2. 打开 cmd（Win+R 输入 cmd 回车），输入：
   netstat -ano | findstr "3001"
   让他把输出**原样念/抄给你**。
3. 判定：输出里既有 LISTENING 又有 ESTABLISHED = 成功；
   只有 LISTENING 没有 ESTABLISHED = 没连上，去故障树。
4. 打开 127.0.0.1:6185（AstrBot 登录页）。

## Phase 8：登录 AstrBot 并填模型 Key
1. 用户名固定填：astrbot
2. 密码：在 AstrBot 的黑色窗口（启动日志）里找带 "password" 或 "密码" 的
   字样，把那串字符照抄到浏览器密码框。**绝不打开 cmd_config.json。**
3. 首次登录会强制改密码：让他设置一个**他自己记得住的**新密码。
4. 登录后进"模型/提供商"设置，找到已配好的那个提供商
   （名字含 strawberry/gemini 字样），把 key 那一栏的
   YOUR_KEY_HERE 换成真人提供给他的真实 key，保存。
   （粘贴后把光标移到 key 最前和最后，确认没有多余空格或换行。）
5. 成功标志：保存后显示配置正常/绿色状态。

## Phase 9：四联验收（每步都让他描述结果）
1. 群里免@回话：让他在目标群里直接发一句"在吗"（不@任何人），
   机器人几十秒内回复 = 过。
2. 识图：发一张图片@机器人或群里发图，机器人描述出图里内容 = 过。
3. 提醒：私聊或在群里说"3分钟后提醒我测试"，3分钟后收到提醒 = 过。
4. 空间动态：等机器人自动发一条说说（可能需要几小时，期间可先做别的），
   或让真人在后台手动触发一次。看到小号空间有新说说 = 过。
全部通过后：恭喜用户，任务完成。

## 故障树
- 6099 登录提示 token 错误：确认复制时没带空格换行；重试一次；不行找真人。
- 扫码后控制台没反应：刷新页面；确认手机点了"确认"。
- netstat 只有 LISTENING 无 ESTABLISHED：token 替换没成功（Phase 6 第 d 步
  重做）；或文件扩展名实际是 .txt（让他开资源管理器"查看→显示→文件扩展名"
  核对）。
- 6185 密码错误：黑色窗口里那行密码是否抄完整；重新抄一次；
  仍不行 → 停止移交真人（可能配置被改动，真人覆盖重装）。
- 填 key 保存后报错：把报错文字原样发给真人（key 本身别发）。
- 机器人不回话：先等 1 分钟；确认群里发消息没@错人；把 AstrBot 黑色窗口里
  最新的几行字抄给真人。
- 填 key 后提示 401/403 或"无效"：先检查 key 粘贴时**首尾有没有多余空格或换行**
  （光标移到最前和最后，删掉多余空格再保存）；仍不行把报错文字发给真人（key 别发）。
- 电脑重启后机器人不说话：机器人不会开机自启。双击 `<安装目录>\启动.bat` 唤醒，
  等窗口显示 READY 即可；想开机自动启动见《客户使用说明》。
- 把 `<安装目录>` 文件夹改名/挪动了：移回原位置（名字改回 `QQBot`），再双击 `启动.bat`。
