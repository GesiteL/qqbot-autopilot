# 小满 QQ 助手 · 客户使用说明

【截图位 1：桌面上的「安装包.exe」】

## 这是什么

小满是一个住在你电脑里的 QQ 聊天助手，会用像朋友一样的语气在群里或私聊里聊天。
它会自己看时间、偶尔发一条生活说说，也能帮你点歌。
所有聊天记录和设置都留在你自己的电脑里，不会上传给交付方。

## 它能做什么

- 在群里不用 @ 也会接话，短句、像群友，不像客服。
- 发图给它，它能看懂图里是什么再回你。
- 说「三分钟后提醒我」，到点它会回来找你。
- 每天自己发 1～3 条生活说说，也会给你的说说点赞、评论。
- 想听歌就报歌名，它帮你点。
- 深夜话更少，不会硬撑着讲大道理。

> 下文里的 `<安装目录>` 指你安装时选的位置，默认是 `C:\QQBot`；
> 装的时候选了 D 盘就是 `D:\QQBot`。记不住就看安装目录里的 `安装信息.txt`。

## 第一步：安装

1. 把 `安装包.exe` 放在桌面或任意空文件夹里。
2. 双击它。如果 Windows 提示"已保护你的电脑"，点"更多信息"→"仍要运行"。
3. 安装程序会问你装在哪个盘（默认 C 盘）。选一个剩 10GB 以上的盘，回车。
   没看到这一问（旧安装包）就继续，会直接装到 `C:\QQBot`。
4. 安装完成会自动开始运行，并打开两个页面。装好后是 `<盘符>:\QQBot`，
   这个文件夹里的 `安装信息.txt` 记着实际路径、安装时间和版本。

【截图位 2：安装完成后自动打开的两个页面】

## 第二步：让 QQ 上线（交付人员陪同）

打开地址以 `127.0.0.1:6099` 开头的页面，用交付人员给你的密码登录，再用手机 QQ 扫码。
详细步骤见同目录的《post-login.md》，由交付人员操作。

【截图位 3：扫码页面】

## 第三步：填写模型 Key

打开地址以 `127.0.0.1:6185` 开头的页面，按同目录的《客户手册-填key.md》填写你自己的 Key。

【截图位 4：模型设置页面】

## 第一次登录后请改密码

在 6185 页面右上角找到"修改密码"，换成只有你知道的密码，并记好。

## 以后怎么启动和关闭

- 双击 `<安装目录>\启动.bat` 启动；已经开着时再双击不会重复启动，只会打开页面。
- 双击 `<安装目录>\停止.bat` 关闭。

【截图位 5：启动.bat 和 停止.bat】

## 想开机自动启动（可选）

1. 右键 `<安装目录>\启动.bat` →「发送到」→「桌面快捷方式」。
2. 按 `Win+R`，输入 `shell:startup` 回车，把快捷方式放进打开的文件夹。
3. 想取消时，删掉这个快捷方式即可。
